# Bloody Sweet - Diwali Landing Page (React + Vite + GSAP)

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Project notes
- One-page React landing page with a 7-slide auto-playing hero carousel.
- GSAP scroll-reveal and hero-image entrance animations.
- Generated photographic assets are stored in `public/images/`.
- Best-seller product cards reveal product details on hover or tap.
- Change the sale percentage with `DISCOUNT` at the top of `src/App.jsx`.
- Product nutrition and ingredient details are illustrative placeholders; replace them with verified store information before publishing.
